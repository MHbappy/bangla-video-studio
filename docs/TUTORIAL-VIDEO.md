# টিউটোরিয়াল ভিডিও — উদাহরণসহ

কিছু বানানো বা শেখানোর ভিডিও শুরু থেকে শেষ পর্যন্ত কীভাবে বানাবেন। উদাহরণ: **ESP32 দিয়ে গ্যাস ডিটেক্টর** (নাম, দাম সব উদাহরণ — নিজেরটা বসাবেন)।

সাধারণ ধাপগুলো: [HOW-TO-USE.md](../HOW-TO-USE.md) · পণ্যের মার্কেটিং ভিডিও: [MARKETING-VIDEO.md](MARKETING-VIDEO.md)

```
আপনি:   কথা রেকর্ড + কাজের B-roll + স্ক্রিন রেকর্ডিং → Resolve-এ কাটা → ui-তে সব + নোট
Claude: "gas-detector প্রসেস করো" → বানান, ক্যাপশন, শট প্ল্যান, অধ্যায়
আপনি:   দেখে বদল বলা
Claude: রেন্ডার + থাম্বনেইল
```

## ১. ক্যামেরার সামনে কী বলবেন

Claude আপনার কথা কাটে না, আগে-পরেও করে না। **এই ক্রমে বললে** অধ্যায় আর গ্রাফিক্স ঠিক জায়গায় বসে:

| ক্রম | অংশ | উদাহরণ |
|---|---|---|
| ১ | হুক | "রান্নাঘরে গ্যাস লিক হলে এই ছোট যন্ত্রটা বেজে উঠবে।" |
| ২ | পরিচয় (একবার) | "আমি মেহেদী হাসান, KarigorLab থেকে।" |
| ৩ | কী বানাব | "আজকে ESP32 দিয়ে একটা গ্যাস ডিটেক্টর বানাব।" |
| ৪ | কী কী লাগবে | "লাগবে তিনটা জিনিস: MQ-2 সেন্সর, বাজার আর ESP32।" |
| ৫ | ধাপগুলো, একটা একটা করে | "প্রথম ধাপ: সেন্সর সোল্ডার করা।" … "এবার কোড আপলোড করি।" |
| ৬ | ফলাফল | "গ্যাস পেলেই বাজার বেজে উঠছে।" |
| ৭ | শেষ কথা | "ভালো লাগলে সাবস্ক্রাইব করুন।" |

দুটো অভ্যাস কাজে দেয়:
- **নতুন ধাপে ঢোকার সময় মুখে বলুন** ("এবার দ্বিতীয় ধাপ…")। Claude সেখানে অধ্যায় কার্ড বসায়, যা থেকে YouTube-এর অধ্যায় তৈরি হয়।
- **কিছু দেখানোর সময় বলুন** "এই জায়গাটা খেয়াল করুন", "এখানে চাপুন"। Claude সেখানে তীর বসায়।

## ২. কোন ফুটেজ লাগবে

ফাইলের নাম দেখেই Claude ক্লিপ বাছে — নামে লিখুন ক্লিপে কী আছে:

| কী | নামের উদাহরণ | কোথায় ব্যবহার হয় |
|---|---|---|
| যন্ত্রাংশের ক্লোজআপ | `esp32-closeup.mp4`, `mq2-sensor-closeup.mp4` | আপনি পাশে, জিনিস পাশে |
| হাতের কাজ | `soldering-sensor.mp4`, `wiring-breadboard.mp4` | পুরো স্ক্রিন |
| স্ক্রিন রেকর্ডিং | `screen-code-upload.mp4`, `screen-arduino-ide.mp4` | স্ক্রিন বড়, আপনি কোণায় ছোট |
| ছবি / ডায়াগ্রাম | `circuit-diagram.png` | পুরো স্ক্রিন, ধীরে জুম |
| শেষ ফলাফল | `detector-working.mp4` | পুরো স্ক্রিন |

- স্ক্রিন রেকর্ডিংয়ের নাম `screen-` দিয়ে শুরু করলে বোঝা সহজ।
- স্ক্রিন রেকর্ডিং আপনার কথার সাথে নিজে মেলে না। কোন জায়গা থেকে দেখাতে হবে নোটে লিখে দিন (নিচে উদাহরণ)।
- স্ক্রিনের লেখা বড় রাখুন (জুম ১২৫–১৫০%) — ফোনে পড়া যাবে।
- `IMG_1234.mp4` ধরনের নাম দেবেন না।

## ৩. রিসোর্স ম্যানেজারে দিন

```bash
npm run ui
```

1. **ভিডিও** ট্যাব: নাম দিন `gas-detector`, কাটা ফুটেজ টেনে আনুন → **তৈরি করো**।
2. কার্ডে **রিসোর্স আর নোট** খুলে B-roll, স্ক্রিন রেকর্ডিং, ছবি সব একসাথে টেনে দিন।
3. **Claude-এর জন্য নোট** লিখুন:

```
- ধরন: টিউটোরিয়াল
- কোথায় যাবে: YouTube
- বিষয়: ESP32 দিয়ে গ্যাস ডিটেক্টর
- নামের বানান: ESP32, MQ-2, Arduino IDE, KarigorLab
- মোট খরচ: ৳১,২৫০
- কোড দেখানোর সময় screen-code-upload.mp4, ০:১৫ থেকে
- সার্কিট বোঝানোর সময় circuit-diagram.png
- সোল্ডারিংয়ের ক্লিপ স্লো-মোশন করো
```

**নামের বানান নোটে লিখে দিন।** ইংরেজি আর টেকনিক্যাল নাম ট্রান্সক্রিপ্টে প্রায়ই ভুল আসে; নোট দেখে Claude ঠিক করে। বারবার লাগে এমন শব্দ `glossary.txt`-এ যোগ করলে সব ভিডিওতে কাজ করবে।

## ৪. Claude-কে বলুন

> **"gas-detector প্রসেস করো"**

মোটামুটি এরকম প্ল্যান হবে:

| আপনি যখন বলছেন | স্ক্রিনে |
|---|---|
| হুক | আপনার মুখ |
| "আমি মেহেদী হাসান…" | মুখ + নিচে নামের বার |
| "কী কী লাগবে" | পুরো স্ক্রিনে **তালিকা**, একটা একটা করে আসে |
| "প্রথম ধাপ…" | **অধ্যায় কার্ড**: অধ্যায় ১ — সোল্ডারিং |
| ESP32 হাতে নিয়ে বোঝানো | আপনি বাঁয়ে, ESP32-এর ক্লোজআপ ডানে |
| "এই জায়গাটা খেয়াল করুন" | ক্লিপের উপর **তীর** + লেখা |
| কোড দেখানো | স্ক্রিন রেকর্ডিং বড়, আপনি কোণায় ছোট; দরকারি লাইনে তীর |
| "খরচ পড়বে ১২৫০ টাকা" | মুখের পাশে **বড় সংখ্যা**: ৳১,২৫০ |
| "Arduino-র চেয়ে ESP32…" | **তুলনা**: Arduino বনাম ESP32 |
| শেষ কথা | মুখ + "সাবস্ক্রাইব করুন" বোতাম, তারপর end screen |

তীরের জায়গা Claude আন্দাজে বসায় না — ওই শটের ছবি বানিয়ে দেখে ঠিক করে।

শেষে Claude জানাবে কোন B-roll কম পড়েছে (যেমন *"০:৫২–১:০১: MQ-2 সেন্সরের ক্লোজআপ দরকার"*)। শুট করে আপলোড করুন, তারপর বলুন: **"নতুন B-roll দিয়েছি, প্ল্যান আপডেট করো"**

## ৬. রেন্ডার আর আপলোড

> **"রেন্ডার করো"** — বা নিজে:

```bash
npm run render -- gas-detector --fast
```
আগে এই দ্রুত প্রিভিউ দেখে নিন।

```bash
npm run render -- gas-detector
```
ফাইনাল → `output/final.mp4`

```bash
npm run render -- gas-detector --format shorts --from 95 --to 140
```
৯৫–১৪০ সেকেন্ড থেকে Shorts → `output/shorts-95-140.mp4`। একটা ধাপ বা শেষ ফলাফল Shorts-এ ভালো চলে।

> **"থাম্বনেইল বানাও, লেখা: ৳১২৫০-এ গ্যাস ডিটেক্টর"**

`media/videos/gas-detector/output/` থেকে YouTube-এ:

| ফাইল | কোথায় |
|---|---|
| `final.mp4` | ভিডিও |
| `thumbnail.jpg` | থাম্বনেইল |
| `captions.srt` | সাবটাইটেল |
| `chapters.txt` | বর্ণনায় পেস্ট করুন — অধ্যায় তৈরি হবে |

YouTube Studio-তে end screen-এর বোতাম (পরের ভিডিও, সাবস্ক্রাইব) ডান দিকের ফাঁকা জায়গায় বসান।
