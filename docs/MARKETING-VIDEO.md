# পণ্যের মার্কেটিং ভিডিও — উদাহরণসহ

একটা পণ্য বিক্রির ভিডিও শুরু থেকে শেষ পর্যন্ত কীভাবে বানাবেন। উদাহরণ: **ATI Laser 6000W কাটিং মেশিন** (নাম, দাম, অফার সব উদাহরণ — নিজেরটা বসাবেন)।

সাধারণ ধাপগুলো: [HOW-TO-USE.md](../HOW-TO-USE.md) · টিউটোরিয়াল ভিডিও: [TUTORIAL-VIDEO.md](TUTORIAL-VIDEO.md)

```
আপনি:   কথা রেকর্ড + পণ্যের B-roll শুট → Resolve-এ কাটা → ui-তে ফুটেজ, B-roll, নোট
Claude: "laser-machine প্রসেস করো" → বানান, ক্যাপশন, শট প্ল্যান
আপনি:   দেখে বদল বলা
Claude: রেন্ডার (Facebook/YouTube + Reels)
```

## ১. ক্যামেরার সামনে কী বলবেন

Claude আপনার কথা কাটে না, আগে-পরেও করে না। তাই **এই ক্রমে বলুন** — তাহলে প্রতিটা অংশে ঠিক গ্রাফিক্স বসবে:

| ক্রম | অংশ | উদাহরণ |
|---|---|---|
| ১ | হুক (প্রথম ৩–৫ সেকেন্ড) | "২৫ মিলি স্টিল কাটছে মাখনের মতো।" |
| ২ | সমস্যা | "হাতে কাটলে সময় লাগে, মাপও ঠিক থাকে না।" |
| ৩ | পণ্য | "এটা ATI Laser 6000W ফাইবার লেজার কাটিং মেশিন।" |
| ৪ | ফিচার (৩–৫টা, একটা একটা করে) | "অটো ফোকাস হেড — প্লেট বদলালে নিজে মাপ ঠিক করে।" |
| ৫ | স্পেক | "পাওয়ার 6000W, কাটার মাপ ৩ বাই ১.৫ মিটার, ওয়ারেন্টি ২ বছর।" |
| ৬ | প্রমাণ | "গাজীপুরের রফিক ভাই ৬ মাস ধরে চালাচ্ছেন।" |
| ৭ | দাম / অফার | "আগে ছিল ১৪ লাখ, এখন ১২ লাখ ৫০ হাজার।" |
| ৮ | কী করতে হবে | "আজই কল করুন, ঢাকায় ডেলিভারি ফ্রি।" |

সব অংশ থাকতেই হবে এমন না। ভুল বললে বা থেমে গেলে সেটা Resolve-এ কেটে তারপর ফুটেজ দিন।

## ২. কোন B-roll শুট করবেন

মার্কেটিং ভিডিওতে **অন্তত ৬০% সময় পণ্য স্ক্রিনে থাকে**, তাই B-roll বেশি লাগে। ফাইলের নাম দেখেই Claude ক্লিপ বাছে — নামে লিখুন ক্লিপে কী আছে:

| কী | নামের উদাহরণ |
|---|---|
| পুরো পণ্য (ওয়াইড) | `laser-machine-wide.mp4` |
| প্রতিটা ফিচারের ক্লোজআপ | `auto-focus-head-closeup.mp4`, `control-panel-closeup.mp4` |
| ব্যবহার হচ্ছে | `laser-cutting-steel.mp4` |
| ফলাফল | `cut-pieces-finished.mp4` |
| কাস্টমার / কারখানা | `customer-rafiq-workshop.mp4` |
| ডেলিভারি / প্যাকিং | `delivery-truck-loading.mp4` |

- `IMG_1234.mp4` ধরনের নাম দেবেন না — Claude সেই ক্লিপ ব্যবহার করবে না।
- মেশিন চলার শব্দ থাকলে ভালো; Claude সেটা কথার নিচে হালকা রাখে।
- স্লো-মোশন চাইলে ৬০fps-এ শুট করুন।
- Reels-এর জন্য চওড়া ক্লিপও চলে: পুরো ছবি দেখায়, পেছনে ঝাপসা। পুরো স্ক্রিন ভরাতে চাইলে নোটে বলুন।

## ৩. রিসোর্স ম্যানেজারে দিন

```bash
npm run ui
```

1. **ব্র্যান্ড** ট্যাব (একবারই): দোকানের নাম, **ফোন নম্বর**, Facebook পেজ, লোগো। ফোন না দিলে ভিডিওতে যোগাযোগের তথ্য আসবে না।
2. **ভিডিও** ট্যাব: নাম দিন `laser-machine`, কাটা ফুটেজ টেনে আনুন → **তৈরি করো**।
3. কার্ডে **রিসোর্স আর নোট** খুলে B-roll সব একসাথে টেনে দিন।
4. **Claude-এর জন্য নোট** লিখুন:

```
- ধরন: পণ্যের মার্কেটিং ভিডিও
- কোথায় যাবে: Facebook + Reels
- পণ্য: ATI Laser 6000W ফাইবার লেজার কাটিং মেশিন
- দাম: ৳১২,৫০,০০০ (আগের দাম ৳১৪,০০,০০০)
- অফার: ঢাকায় ফ্রি ডেলিভারি, ৩০ নভেম্বর পর্যন্ত
- স্পেক: পাওয়ার 6000W · কাটার মাপ ৩ × ১.৫ মিটার · স্টিল ২৫ মিমি পর্যন্ত · ওয়ারেন্টি ২ বছর
- রিভিউ: "মেশিনটা নেওয়ার পর আমাদের কাজ দ্বিগুণ হয়েছে" — রফিকুল ইসলাম, স্টিল ওয়ার্কশপ, গাজীপুর
- কাটার ক্লিপে মেশিনের শব্দ রাখো
```

**নোটে যা লিখবেন, শুধু তা-ই স্ক্রিনে যাবে।** দাম, ছাড়, ওয়ারেন্টি, রিভিউ — আপনি ভিডিওতে না বললে আর নোটেও না লিখলে Claude নিজে বানিয়ে বসাবে না।

## ৪. Claude-কে বলুন

> **"laser-machine প্রসেস করো"**

Claude বানান ঠিক করবে, ক্যাপশন বানাবে, শট প্ল্যান করবে, তারপর থামবে। মোটামুটি এরকম প্ল্যান হবে:

| আপনি যখন বলছেন | স্ক্রিনে |
|---|---|
| হুক | কাটার ক্লিপ (শব্দসহ) + উপরে ছোট শিরোনাম |
| সমস্যা | আপনার মুখ |
| পণ্যের নাম | পুরো মেশিনের শট + নিচে নামের বার: "ATI Laser 6000W" |
| প্রতিটা ফিচার | সেই ফিচারের ক্লোজআপ + নামের বার, বা মেশিনের অংশে তীর |
| স্পেক | মেশিনের শটের উপর **স্পেক টেবিল** |
| রফিক ভাইয়ের কথা | কাস্টমারের ক্লিপ + **রিভিউ কার্ড** (কথা, নাম, জায়গা) |
| দাম | **অফার কার্ড**: ৳১৪,০০,০০০ কাটা পড়ে → ৳১২,৫০,০০০ বড় হয়ে আসে |
| শেষ কথা | আপনার মুখ + "আজই অর্ডার করুন" বোতাম + ফোন নম্বরের বার |

শেষে Claude জানাবে:
- কোন B-roll কম পড়েছে (যেমন *"০:২২–০:২৬: অটো ফোকাস হেডের ক্লোজআপ দরকার"*)
- কোন তথ্য স্ক্রিনে দেয়নি, কারণ ভিডিও বা নোটে ছিল না
- Reels-এর জন্য সেরা ২০–৬০ সেকেন্ড কোনটা

B-roll কম পড়লে শুট করে আপলোড করুন, তারপর বলুন: **"নতুন B-roll দিয়েছি, প্ল্যান আপডেট করো"**

| স্পেক | "স্পেকগুলো মেশিনের শটের উপর টেবিলে দাও" |
| রিভিউ | "রফিক ভাইয়ের রিভিউটা কার্ডে দেখাও, ৫ তারা" |
| ফিচারের নাম | "০:২০-এ কন্ট্রোল প্যানেলের ক্লিপের উপর লেখো: টাচ কন্ট্রোল — সহজে চালানো যায়" |

## ৬. রেন্ডার

> **"রেন্ডার করো"** — বা নিজে:

```bash
npm run render -- laser-machine --fast
```
আগে এই দ্রুত প্রিভিউ দেখে নিন (অর্ধেক মাপ)।

```bash
npm run render -- laser-machine
```
Facebook / YouTube-এর ১৬:৯ ভিডিও → `output/final.mp4`

```bash
npm run render -- laser-machine --format shorts
```
পুরো ভিডিও খাড়া মাপে (Reels / Facebook) → `output/shorts.mp4`

```bash
npm run render -- laser-machine --format shorts --from 12 --to 48
```
শুধু ১২–৪৮ সেকেন্ড, খাড়া মাপে। কোন সময়টা নেবেন Claude রিপোর্টে বলে দেয়।

ফাইলগুলো থাকে `media/videos/laser-machine/output/`-এ।
