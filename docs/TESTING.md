# টেস্ট গাইড — ধাপে ধাপে

তিন পর্যায়: **(ক) ডেমো** (নিজের ফুটেজ ছাড়া, সেটআপ যাচাই) → **(খ) ১–২ মিনিটের নিজের ক্লিপ** (বাংলা মান ও গতি) → **(গ) পুরো ভিডিও**।

---

## (ক) ডেমো — ২০–৩০ মিনিট

### ১. ইনস্টল
```bash
node -v          # v20+
npm install
npm run setup    # মডেল ~১.১GB + SFX
```
✅ শেষে `✓ সেটআপ শেষ`। ❌ `node` নেই → nodejs.org থেকে LTS।

### ২. ডেমো বানানো
```bash
npm run demo
```
প্রথমবার Remotion নিজের Chrome নামায় (~১০০MB)। তারপর `media/videos/demo/`-এ নকল A-roll (৪০s), ৪টা B-roll, মিউজিক, ট্রান্সক্রিপ্ট আর `edit.json`। ৩–৬ মিনিট।
✅ `✓ ডেমো তৈরি`

### ৩. প্ল্যান যাচাই
```bash
npm run plan
```
✅ ১২টা শটের টেবিল; শট ২-এ `[punch 1.1]` (অটো-পাঞ্চ), শট ১২-এ `[zoom 1.08]`। একটা চ্যাপ্টার-সতর্কতা আসবে (ডেমোতে চ্যাপ্টার একটাই) — স্বাভাবিক।

### ৪. প্রিভিউ
```bash
npm run studio
```
বাঁ দিকে **Main** → Play। মিলিয়ে নিন:

| সময় | যা দেখার কথা |
|---|---|
| 0–3s | পুরো A-roll, নিচে বাংলা ক্যাপশন |
| 3–6s | A-roll একটু বড় ক্রপে (পাঞ্চ) + নামের লোয়ার-থার্ড, "পপ" শব্দ |
| 6–9s | বাঁয়ে A-roll, ডানে B-roll; "হুশ" শব্দ |
| 9–12s | A-roll + হলুদ বৃত্ত আর তীর মুখের দিকে ("সেন্সর এখানে") |
| 12–15s | পুরো B-roll, ধীরে জুম |
| 15–19s | মোশন লিস্ট — প্রতিটা আইটেম আসার সময় পপ; ক্যাপশন নেই |
| 19–22s | A-roll + ডানে "৳১,২৫০" গুনে গুনে বাড়ে |
| 22–26s | মোশন: Arduino vs ESP32 তুলনা |
| 26–30s | কোড স্ক্রিন বড়, কোণে ছোট A-roll; ক্যাপশন বাঁয়ে সরে |
| 30–33s | "অধ্যায় ২" মোশন, নিচে-ডানে বৃত্তে A-roll |
| 33–36s | সার্কিটের ছবি, ধীরে জুম |
| 36–40s | A-roll ধীরে জুম + উপরে "সাবস্ক্রাইব করুন" |

শব্দ: A-roll-এর টোন **পুরো ৪০ সেকেন্ড একটানা**; মিউজিক কথার সময় নিচু, বিরতিতে উঁচু; লেআউট বদলে whoosh।
বাঁ দিকে **Vertical** বেছে নিন → একই এডিট খাড়া (split উপরে-নিচে, PiP উপরে-বাঁয়ে, বড় শব্দ-হাইলাইট ক্যাপশন)।

### ৫. রেন্ডার
```bash
npm run render -- --fast                         # দ্রুত প্রিভিউ → output/final-preview.mp4
npm run render                                   # ফাইনাল → output/final.mp4 (লাউডনেস রিপোর্ট দেখাবে)
npm run render -- --format shorts --from 0 --to 20
npm run render -- --format graphics --from 0 --to 10
```
✅ ফাইল প্লে করে স্টুডিওর মতো; graphics.mov-এ ব্যাকগ্রাউন্ড স্বচ্ছ (Resolve-এ টেনে দেখুন)।
**ফাইনাল রেন্ডারের সময় নোট করুন** — ৪০s-এ যত লাগল, ১০ মিনিটে মোটামুটি ১৫ গুণ।

### ৬. এডিট বদলে দেখুন
`media/videos/demo/edit.json`-এ শট ৩-এর `"split"` → `"pip"` করুন → `npm run plan` → স্টুডিও রিফ্রেশ।
ইচ্ছা করে ভুল দিন (`"broll": "nai.mp4"`) — `plan` বাংলায় ধরবে।
Claude-কে বলেও দেখুন: "demo-র শট ৭ Compare করো" — Skill দিয়ে শুধু ওই শট বদলাবে।

## (খ) নিজের ছোট ক্লিপ — ৩০–৬০ মিনিট
উদ্দেশ্য: বাংলা ট্রান্সক্রিপশনের নির্ভুলতা আর গতি মাপা, পুরো ফ্লো একবার নিজে চালানো।

1. Resolve থেকে ১–২ মিনিটের কাটা অংশ (CFR, অডিও পরিষ্কার)
2. `npm run new -- test-clip <ফাইল>` → শেষে কত সেকেন্ড লাগল দেখায়
   - `media/videos/test-clip/work/raw.srt` পড়ুন: ১০ লাইনে কয়টা ভুল?
   - ভুল বেশি → `--quality accurate` (বা `.env`-এ `QUALITY=accurate`); ধীর হলে জানান
3. ৩–৫টা B-roll বর্ণনামূলক নামে → `media/videos/test-clip/broll/`
4. Claude: **"test-clip-এর captions ঠিক করো"** → `npm run finalize`
   ✅ `output/captions.srt`-এ বানান ঠিক, সময় অপরিবর্তিত; নতুন শব্দ glossary-তে যোগ করুন
5. Claude: **"edit plan বানাও"** → নিজে `npm run plan` চালিয়ে ঠিক করবে, কোথায় B-roll কম তার তালিকা দেবে
6. `npm run studio` → দেখুন; বদল Claude-কে সহজ ভাষায় ("শট ৪ split করো", "০:৪০-এ মুখ দেখাও")
7. `npm run render` → ফোন আর কম্পিউটারে দেখুন:
   - [ ] ক্যাপশন পড়া যায়, বানান ঠিক
   - [ ] অডিও-ভিডিও মিলছে
   - [ ] কাট বাক্যের মাঝে পড়ছে না
   - [ ] B-roll কথার সাথে মানানসই
   - [ ] মিউজিক কণ্ঠ ঢাকছে না
   - [ ] লাউডনেস অন্য YouTube ভিডিওর মতো

## (গ) পুরো ভিডিও
(খ)-এর মতোই। বাড়তি:
- আগে `npm run render -- --fast` দিয়ে পুরোটা দেখে নিন
- `output/chapters.txt` → YouTube ডেসক্রিপশনে; `output/captions.srt` → YouTube সাবটাইটেল হিসেবে আপলোড
- Shorts: ভালো ৩০–৬০ সেকেন্ডের অংশ Claude-কে খুঁজতে বলুন → `--format shorts --from --to`

| লক্ষণ | সমাধান |

| প্রথম রেন্ডারে Chrome নামাতে ব্যর্থ | ইন্টারনেট দেখুন, আবার চালান |

| বাংলা ভুল বেশি | পরিষ্কার মাইক, `--quality accurate`, glossary বাড়ান |
