# রিসোর্স গাইড — আপনি কী দেবেন

পাইপলাইন কাটে না, শুট করে না। আপনার দায়িত্ব: **ভালো A-roll + মানানসই B-roll + মিউজিক**। বাকিটা Claude আর কোড।

## ফোল্ডার

```
media/
├── library/                 ← সব ভিডিওর জন্য শেয়ার্ড (জমতে থাকে)
│   ├── broll/               ← বারবার কাজে লাগে এমন B-roll (ওয়ার্কশপ, যন্ত্রপাতি, লোগো)
│   ├── music/               ← লাইসেন্স-মুক্ত মিউজিক
│   ├── brand/               ← logo.png, qr.png, brand.json (নাম, ঠিকানা, ফোন, সোশ্যাল)
│   └── sfx/                 ← whoosh.wav, pop.wav (ডিফল্ট তৈরি হয়; ভালো থাকলে একই নামে বদলান)
└── videos/
    └── gas-detector/        ← প্রতিটা ভিডিওর নিজের ফোল্ডার (npm run new বানায়)
        ├── aroll.mp4        ← আপনার কাটা ফুটেজ (new কমান্ড কপি করে)
        ├── broll/           ← শুধু এই ভিডিওর B-roll  ← আপনি রাখবেন
        ├── music/           ← (ঐচ্ছিক) শুধু এই ভিডিওর মিউজিক
        ├── transcript.json  ← Claude
        ├── edit.json        ← Claude (আপনি বদলাতে পারেন)
        ├── captions-index.txt, captions.json, timeline.json, assets.json, project.json  ← স্বয়ংক্রিয়
        └── output/          ← final.mp4, shorts.mp4, graphics.mov, captions.srt, chapters.txt
glossary.txt                 ← টেকনিক্যাল শব্দের বানান (সব ভিডিওর জন্য)
src/theme.ts                 ← ব্র্যান্ড (একবার)
```

একই নামের B-roll ভিডিওর ফোল্ডার আর লাইব্রেরি দুটোতে থাকলে ভিডিওর ফোল্ডারেরটা নেওয়া হয়।

## ১. A-roll — সবচেয়ে গুরুত্বপূর্ণ

Resolve-এ (বা যেকোনো এডিটরে) **কাটা + কালার গ্রেড + অডিও পরিষ্কার** করে এক্সপোর্ট:

| সেটিং | মান | কেন |
|---|---|---|
| ফ্রেমরেট | **স্থির (CFR)** 25 বা 30 | ফোনের VFR ফুটেজে অডিও-ভিডিও সরে যায় |
| রেজোলিউশন | 1920×1080 বা 3840×2160 | ফাইনাল এই মাপে হবে; 4K দিলে পাঞ্চ-ইনেও শার্প থাকে |
| কোডেক | H.264 ৪০–৮০ Mbps, বা ProRes 422 | Remotion আবার এনকোড করে — উৎস যত ভালো, ফল তত ভালো |
| অডিও | Voice Isolation, Dialogue Leveler, হালকা কম্প্রেশন | পাইপলাইন শুধু লাউডনেস মাস্টার করে, শব্দ পরিষ্কার করে না |
| কালার | গ্রেড Resolve-এই শেষ | Remotion কালার গ্রেড করে না |

**ফ্রেমিং:** মুখ মাঝখানে, উপরের তৃতীয়াংশে — split/PiP/বৃত্তে আর Shorts-এর খাড়া ক্রপে মুখ ঠিক থাকে। অন্য জায়গায় বসলে `edit.json`-এ `"arollFocus": "35% 35%"` (x% y%)।
**৪K-তে শুট করে ১০৮০p টাইমলাইন** হলে আরও ভালো — কিন্তু তখন A-roll 4K-তেই এক্সপোর্ট করুন।

## ২. B-roll — মান এখানেই আসে

**নাম দেখেই Claude ঠিক করে কোথায় বসাবে।** বর্ণনামূলক নাম দিন:

| ✅ ভালো | ❌ খারাপ |
|---|---|
| `esp32-closeup-hand.mp4` | `IMG_4521.mp4` |
| `soldering-mq2-sensor.mp4` | `clip2.mp4` |
| `screen-arduino-ide-upload.mp4` | `screen.mp4` |
| `buzzer-beeping-alarm.mp4` | `final_final.mp4` |

- **দৈর্ঘ্য:** ৫–১৫ সেকেন্ড। ছোট হলে লুপ হয় (`npm run plan` সতর্ক করে)।
- **মান:** A-roll-এর সমান বা বেশি রেজোলিউশন; স্থির, ফোকাসড, ভালো আলো। ঝাঁকুনি থাকলে গিম্বল/ট্রাইপড।
- **ছবি:** jpg/png, কমপক্ষে ১৯২০px চওড়া — নিজে থেকে ধীর জুম হয়।
- **খাড়া না আড়াআড়ি:** দুটোই চলে। ফোনে খাড়া তোলা ক্লিপ ১৬:৯ ভিডিওতে পুরোটা দেখায় (দুই পাশে ঝাপসা কপি); আড়াআড়ি ক্লিপ Shorts-এ একইভাবে। Reels/Shorts-ই মূল লক্ষ্য হলে পণ্য ফ্রেমের মাঝখানে রাখুন, তাহলে পুরো স্ক্রিন ভরানো (`fill`) যায়।
- **শব্দ:** B-roll-এর শব্দ সবসময় বন্ধ।
- **কত লাগবে:** প্রতি মিনিট ভিডিওতে মোটামুটি ৪–৬টা ক্লিপ। কম থাকলে Claude জানাবে কোথায় কী শট দরকার।
- **শুটিং টিপ:** প্রতিটা জিনিসের ৩ ধরনের শট — ওয়াইড, মিডিয়াম, ক্লোজআপ (হাতে ধরে), প্রতিটা ৮–১০ সেকেন্ড। স্ক্রিনের কাজ OBS দিয়ে 1080p-তে।
- **স্টক:** Pexels, Pixabay (ফ্রি, লাইসেন্স দেখে নিন)।

তালিকা দেখতে: `npm run assets`

## ৩. মিউজিক
- লাইসেন্স-মুক্ত: YouTube Audio Library, Pixabay Music। কপিরাইট ক্লেইম এড়াতে অন্য কিছু নয়।
- নাম মুড অনুযায়ী: `calm-tutorial-01.mp3`, `upbeat-intro.mp3` — Claude নাম দেখে বাছাই করে।
- ভোকাল (গান) ছাড়া ইনস্ট্রুমেন্টাল — কণ্ঠের সাথে সংঘর্ষ হয় না।
- কথার সময় নিজে থেকেই নিচু হয়; ছোট হলে লুপ।

## ৪. সাউন্ড ইফেক্ট
`media/library/sfx/whoosh.wav` (লেআউট বদলে) আর `pop.wav` (গ্রাফিক্স আসার সময়)। ডিফল্টগুলো সাধারণ; ভালো SFX প্যাক থেকে **একই নামে** বদলে দিলে সব ভিডিওতে কাজ করবে। পুরো বন্ধ: `edit.json`-এ `"sfx": false`।

## ৫. glossary.txt
Whisper যে শব্দ ভুল লেখে তার সঠিক রূপ — `ESP32  ←  ইএসপি থার্টি টু`। Claude নতুন শব্দ পেলে জানাবে।

## ৬. লোগো, ফোন, সোশ্যাল, QR — media/library/brand/
`logo.png` (স্বচ্ছ PNG, অন্তত ৪০০px চওড়া), ইচ্ছা হলে `qr.png`, আর `brand.json`-এ নাম/ঠিকানা/ফোন/সোশ্যাল। সব ভিডিওতে কোণায় লোগো আর মাঝে মাঝে যোগাযোগ বার বসে। ভরার নিয়ম: [WHERE-TO-PUT.md](../WHERE-TO-PUT.md), সব অপশন: [SETTINGS.md](SETTINGS.md)।

## ৭. ব্র্যান্ডের রং — src/theme.ts
`accent` (হাইলাইট রং), `accent2`, প্যানেলের রং, কোণ, অ্যানিমেশনের গতি। একবার ঠিক করুন — সব ভিডিওতে একই লুক। ফন্ট বদলাতে Claude-কে বলুন।
